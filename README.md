# AR Анатомия

Интерактивный 3D-атлас в дополненной реальности для изучения анатомии.

Сайт: https://anatomia-ar.netlify.app

О проекте
Бесплатный образовательный проект. Позволяет изучать анатомические структуры через 3D-модели и дополненную реальность в браузере смартфона. Без установки. Без подписок. Open Source.

Возможности
- Работает в браузере смартфона
- 3D-модели с вращением и масштабированием
- AR-режим (модель на любой поверхности)
- Описание, латынь, теги для запоминания
- Загрузка своих моделей через Telegram-бота
- Открытый исходный код

Библиотека органов (12 шт.)
Желудок, Печень, Поджелудочная железа, Тонкая кишка, Толстая кишка, Лёгкое, Гортань, Трахея и бронхи, Почка, Мочевой пузырь, Матка с придатками, Почка и надпочечник

Технологии
- 3D/AR: Google Model-Viewer, WebXR
- Формат моделей: glTF / .glb
- Фронтенд: HTML5 + CSS3 + JavaScript
- Хостинг: Netlify
- Контент: Telegram-бот

Структура проекта
ar-anatomy/
├── index.html          # Страница с 3D-моделями
├── home.html           # Главная страница
└── mods/               # 3D-модели (.glb)

Быстрый старт
1. Открыть сайт
2. Выбрать орган из списка
3. Нажать "Перейти"
4. Вращать, масштабировать, изучать
5. Нажать "Смотреть в AR" — модель в реальном мире

Как внести вклад
1. Энтузиаст-разработчик? - загружайте 3D-модели через Telegram-бота @modelexchangebot
2. Медик? - помогайте проверять точность моделей
3. Разработчик? - делайте форк и отправляйте Pull Request
